TranscriptX

Think with your transcripts — on your machine.

A local-first personal transcript analysis workbench: import, explore language and speakers, run structured analyses with optional local AI, and export results you keep.

Get started View on GitHub

Install

Recommended path: Docker full analysis. Native install is documented in the repository. TranscriptX does not transcribe audio in-app — use the Transcribe Audio command generator, then import. 

git clone https://github.com/glen-w/TranscriptX.git
cd TranscriptX
docker compose up

Local-first

Source material and analysis outputs stay on your machine. Optional local AI via Ollama. No hosted SaaS analysis path in 1.0 scope.
