# Explore Charts for a finished run

Open the run-scoped **Charts** view to see visual module outputs without leaving the analysis context.

## Outcome

You will have opened **Charts** for the planning-review run and oriented on at least one chart or module panel produced by analysis.

## Starting point

The planning-review transcript is [imported](../runtime/transcription.md) and a completed analysis run is selected (from [First analysis](first-analysis.md)). Local AI is not required.

## What you’ll do

1. Confirm the transcript and run in the workspace pickers.
2. Open **Charts**.
3. Skim available charts / module visuals.
4. Decide whether to return to **Insights** or **Overview** for prose context.

## Walkthrough

1. In the sidebar, select the planning-review transcript and the completed run you care about.

2. Open **Charts**. The page is run-scoped: if no subject/run is selected, TranscriptX will nudge you back toward Home/Overview rather than showing an empty chart shell.

3. Scan the chart gallery or module sections for visuals that answer a concrete question (for example speaker share, topic shift, or interaction patterns — depending on which modules completed).

4. If a chart looks sparse, check **Overview** run status for skipped/failed modules before assuming the feature is broken. Re-run with **Balanced** or **Thorough** after naming speakers ([Identify and name speakers](speaker-identification.md)) when speaker-aware charts are empty.

5. Use **Insights** when you need quotable evidence; use **Charts** when you need a spatial/time overview of the same run.

## What to notice

- Charts require a **run-scoped** context, same as Overview / Insights / Artifacts.
- Empty panels usually mean the producing module skipped (offline downloads disabled, missing names, or preset exclusions) — not a navigation bug.
- Charts complements Insights; it does not replace jumping back to **Transcript** for full context.

## You should now have…

A finished-run Charts view open, plus a sense of which visuals are worth following into Insights or Transcript.
