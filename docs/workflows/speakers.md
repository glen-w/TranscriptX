# Browse longitudinal speaker profiles

Open the **Speakers** directory to review profiles linked across managed transcripts (when you enrol speakers during identification).

## Outcome

You will have opened **Speakers**, found a longitudinal profile, and understood how it relates to per-transcript Speaker Identification.

## Starting point

Prefer completing [Identify and name speakers](speaker-identification.md) with **Also link to longitudinal speaker profile** enabled at least once. For a quick look, any existing profile in the Speakers directory is enough. Local AI is not required.

## What you’ll do

1. Open **Speakers**.
2. Confirm profiles are listed (not the empty state).
3. Open one profile and note display name / link summary.
4. Know when to return to Speaker Identification vs Speakers settings.

## Walkthrough

1. Open **Speakers** from the primary sidebar section.

2. If you see **No speaker profiles yet**, go back to **Speaker Identification**, name a speaker, and enable linking to a longitudinal profile, then return here. Settings → Speakers controls inclusion / enrol caps — see [Settings & knobs](../runtime/settings.md).

3. When profiles exist, select one (for example a facilitator named during walkthrough 2). Confirm the display name and any transcript-link summary shown on the detail surface.

4. Use Speakers for cross-transcript continuity; use **Speaker Identification** for naming on a single transcript before analysis. Voice-match / enrol behaviour is optional and install-dependent.

5. After linking, re-open Speakers to confirm the profile still resolves — this is the durable directory, not a one-shot wizard result.

## What to notice

- Speakers profiles are longitudinal; diarized `SPEAKER_00` labels on a transcript are local until named and optionally linked.
- Empty Speakers is normal on a brand-new library — create links from Speaker Identification rather than inventing profiles here.
- Privacy-sensitive voice evidence (when enabled) follows Speakers / Settings policy — keep disposable data roots for experiments.

## You should now have…

Opened the Speakers directory and located at least one longitudinal profile (or a clear path to create the first link).
