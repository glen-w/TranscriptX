# Accessibility baseline (2026-11-03)

Advisory snapshot for GUI hardening **W4**. Not a PR gate yet — axe criticals become blocking after this baseline is re-measured on a green shell-smoke week.

## How this was taken

- Shell smoke already visits every `PAGE_SPECS` page (Playwright, 1440×900, tiny seeded library).
- This note records known Streamlit gaps rather than a full axe-core inventory (axe lands as an advisory pass on Home / Library / Overview / Run Analysis / Settings).

## Known issues (do not regress silently)

| Area | Issue | Mitigation in this wave |
|------|--------|-------------------------|
| Icon-only action links | Streamlit nbsp label → empty `button-name` | Action name is the button label; CSS clips it visually (`tx_al_i_` keys) |
| Collapsed widget labels | `label_visibility="collapsed"` on hub segmented controls | Settings section, Tools tool, sidebar Type now visible. Remaining collapsed widgets keep a non-empty label (placeholder / adjacent control). Count is still above the W4.3 “≤ 5” target. |
| Chart iframes | Plotly/static iframes need a preceding accessible caption | Full-screen HTML charts are preceded by `module · title` (`st.caption` immediately before `st.iframe`). Gallery cards already caption; they do not inline iframes. |
| Streamlit chrome | Sidebar collapse, file uploader, dataframe | Upstream; do not patch with brittle DOM hacks |
