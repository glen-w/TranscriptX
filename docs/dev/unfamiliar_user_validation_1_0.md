# Unfamiliar-user validation (1.0)

**Status:** planning  
**Programme:** [pre_release_roadmap_1_0.md](pre_release_roadmap_1_0.md) §14  
**Related:** [manual_acceptance_1_0.md](manual_acceptance_1_0.md), [release_severity_triage_1_0.md](release_severity_triage_1_0.md)

The 1.0 success criterion centres on an unfamiliar user. Run during indicative **0.9.x hardening / pre-RC** once install and principal journeys are stable enough to evaluate.

## Mandatory protocol

- [ ] Two to five people who have **not** developed TranscriptX
- [ ] At least one relatively **non-technical** user
- [ ] **Fresh machine** or fresh environment
- [ ] **No live coaching** unless they become completely blocked
- [ ] Record: installation time; time to first useful result; blockers; misunderstood terminology; abandoned journeys
